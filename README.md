# DualComp

Official code repository for **Semantic-Geometric Dual Compression: Training-Free Visual Token Reduction for Ultra-High-Resolution Remote Sensing Understanding**.

> **Release status:** public source preparation is in progress.

- No model or router weights are included in this release.
- All numerical results will be transcribed from the manuscript and marked as paper-reported, not independently reproduced.
- The reviewed clean-room reference implementation, provenance record, and reproducibility notes will be added in subsequent updates.
- Missing paper parameters will remain explicit; undocumented private defaults will not be presented as paper settings.

Original source code will be released under Apache-2.0. Third-party models, datasets, weights, and integrations remain subject to their own terms.
